PRISM_WORKLET TABLE
-------------------
CSV Column          → DB Column                    → Notes
-----------------------------------------------------------------------------
WorkletDescription  → Title                        → Main title
StatusID            → StatusID                     → Foreign key to status table
Mentor1EmailID      → CreatedMentorID (via lookup) → References users.user_id
College             → CollegeID (via lookup)       → References colleges.college_id
AssignedDate        → StartDate                    → Uses datetime.now() if NULL
CreatedOn           → CreatedOn                    → Uses datetime.now() if NULL
RiskStatus          → RiskStatus                   → Nullable
PerformanceStatus   → Performance                  → Nullable
(hardcoded)         → IsActive                     → Always 1
ImagePath           → ImagePath                    → Defaults to empty string ''
ProblemStmt         → ProblemStmt                  → Defaults to empty string ''
Expectations        → Expectations                 → Defaults to empty string ''
Prerequest          → Prerequest                   → Defaults to empty string ''
TechDomainID        → TechDomainID                 → Defaults to 1 if missing/0
(hardcoded/default) → Progress                     → Defaults to 0
EndDate             → EndDate                      → Defaults to StartDate + 180 days
CertID              → CertID                       → Nullable, unique
TeamID              → TeamMGID                     → Direct mapping from CSV TeamID to TeamMGID
GitPath             → GitHubUrl                    → Direct mapping from CSV


TEAMMG TABLE
------------
NOT POPULATED FROM CSV - TeamID from CSV is inserted directly into Prism_Worklet.TeamMGID
TeamMG table should be pre-populated with existing team records in the database.
